# ArtifactRun

ArtifactRun is a top-down action, exploration, base-defense, and logistics game being developed in Godot.

The current development goal is a compact vertical slice built around exploring alien ruins, excavating an artifact, surviving a day/night cycle, and defending the artifact while it is transported by rail to a company outpost.

See [VERTICAL_SLICE_GDD.md](VERTICAL_SLICE_GDD.md) for the current design.

## Archived prototype

The previous LibGDX implementation is preserved under `archive/libgdx-project-2025/`. It is retained as historical reference and is not part of the new Godot project.
